# Octelium SDK and API NPM Packages

This repository contains Octelium npm packages, currently:

-  `@octelium/sdk` to create an Octelium client to interact with the _Cluster_ via its APIs (e.g. control the _Cluster_ resources such as _Users_, _Services_, etc.)
- `@octelium/apis` which mostly contains the compiled protobuf definitions of the different Octelium APIs.
